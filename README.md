# Mini_Project_Power_BI_Dashboard_DA36
This FIFA 21 Player Analytics Overview transforms data from 18,979 players and 682 clubs into interactive scouting insights. Focused on the "Player Profile Analysis," it uses advanced visuals to evaluate performance, skill sets, and market value, turning raw datasets into a powerful tool for data-driven football evaluation.
I cleaned and transformed raw FIFA 21 data using Excel and Power Query, then developed a Power BI dashboard driven by DAX measures to visualize player performance and market trends.
